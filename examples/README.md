# Binance期货API测试程序

## 概述

本目录包含两个Binance期货API测试工具：

- `binance_futures_test.rs` - 通用的Binance期货API测试工具（USDT账户）
- `binance_futures_usdc_test.rs` - 专门针对USDC账户的测试工具

两个工具都用于验证API连接、账户信息查询、市场数据获取和交易功能。

## 功能特性

### 🔗 连接测试
- 服务器时间同步检查
- 交易所信息获取
- API连接状态验证

### 💰 账户功能
- **USDT版本**: USDT余额查询、总钱包余额显示
- **USDC版本**: USDC余额查询、可用余额显示、总钱包余额显示
- 账户信息详细展示

### 📊 持仓管理
- 所有持仓信息查询
- 活跃持仓统计
- 持仓详情展示

### 📈 市场数据
- 订单簿深度数据
- 24小时价格统计
- 实时价格信息
- **USDC版本**: 专门测试USDC交易对（如BTCUSDC）

### ⚡ 交易功能
- 小额测试订单下单
- 订单状态查询
- 订单取消功能
- 安全的交易测试（远离市价的限价单）
- **USDC版本**: 使用USDC计价的交易对进行测试

## 使用前准备

### 1. 配置API密钥

确保 `api_config.toml` 文件已正确配置：

```toml
[binance.futures]
api_key = "your_api_key_here"
secret_key = "your_secret_key_here"
base_url = "https://fapi.binance.com"
```

### 2. API权限要求

确保您的API密钥具有以下权限：
- ✅ 读取权限（查询账户、持仓、市场数据）
- ✅ 交易权限（下单、取消订单）
- ❌ 不需要提现权限

## 运行测试

### 编译测试程序

```bash
# USDT版本
cargo check --example binance_futures_test

# USDC版本
cargo check --example binance_futures_usdc_test
```

### 运行完整测试

```bash
# USDT账户测试
cargo run --example binance_futures_test

# USDC账户测试
cargo run --example binance_futures_usdc_test
```

## 测试流程

### 阶段1：基础连接测试
1. **服务器时间同步** - 验证与Binance服务器的连接
2. **交易所信息** - 获取支持的交易对数量

### 阶段2：账户信息验证
3. **账户余额** - 显示余额和总钱包余额（USDT版本显示USDT余额，USDC版本显示USDC余额）
4. **持仓信息** - 展示当前持仓状态

### 阶段3：市场数据测试
5. **深度数据** - 获取订单簿（USDT版本使用BTCUSDT，USDC版本使用BTCUSDC）
6. **价格统计** - 显示24小时价格变化

### 阶段4：交易功能测试（可选）
7. **安全下单** - 下一个远离市价的小额限价单
8. **订单取消** - 立即取消测试订单

## 安全特性

### 🛡️ 交易安全保护
- **小额测试**：仅使用0.001 BTC的测试数量
- **远离市价**：限价单设置为市价的50%，确保不会成交
- **用户确认**：交易测试需要用户明确确认
- **立即取消**：测试订单会在1秒后自动取消
- **币种适配**：USDC版本使用USDC计价交易对

### 🔒 配置安全
- API配置文件已添加到`.gitignore`
- 不会在日志中显示敏感信息
- 支持测试网和正式网环境切换

## 故障排除

### 常见问题

**Q: 编译失败怎么办？**
A: 运行 `cargo clean` 后重新编译

**Q: API连接超时？**
A: 检查网络连接和防火墙设置

**Q: 权限不足错误？**
A: 确认API密钥具有必要的读取和交易权限

**Q: 测试订单真的会被取消吗？**
A: 是的，程序会在1秒后自动取消测试订单
